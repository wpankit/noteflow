# Security policy

## Supported versions

Security fixes are released for the latest version of the plugin on [WordPress.org](https://wordpress.org/plugins/noteflow/). Please keep it up to date.

## Reporting a vulnerability

Please **don't** report security issues in public issues, pull requests or the support forum.

Report them privately on GitHub: open the repository's **Security** tab and choose **Report a vulnerability**, or go straight to [the private report form](https://github.com/wpankit/noteflow/security/advisories/new).

Examples of what counts: someone reading, editing or deleting a note that wasn't shared with them, seeing a discussion on a post they can't edit, or a user without access to NoteFlow reaching its screens or its REST API.

Please include:

- the plugin version affected,
- what the vulnerability is and what an attacker could do with it,
- the roles involved, and the settings or sharing it needs,
- steps to reproduce it, or a proof of concept.

You'll get an acknowledgement as soon as possible, usually within a few days. Once the issue is confirmed, a fix is released on WordPress.org, and you're credited in the advisory unless you'd rather not be.
